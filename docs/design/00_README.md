# 중공 원통 입수충격 해석기 — 설계 문서 묶음

구현 착수 전 설계 단계 문서입니다. 계산 코드는 아직 없습니다.

| 파일 | 내용 |
|---|---|
| `01_environment_check.md` | 실행 환경 읽기 전용 확인 결과 (※ 클라우드 컨테이너 결과, 워크스테이션 아님) |
| `02_design_document.md` | 문제 정의, 방법 비교·권고, 항목별 처리 방법과 한계, 실행/검증 구분, 입력 분리 규칙 |
| `03_verification_plan.md` | 단계별 검증: 비교 대상, 측정 지표, 통과 기준과 근거 유형 |
| `04_development_phases.md` | 개발 단계표 (P0–P9), 진입/종료 조건 |
| `05_open_decisions.md` | 미결정 항목 (지금 결정 / 단계 전 / 논문 조건) |
| `06_references.md` | 참고문헌과 확인 수준 |

핵심 규칙
1. 실행 성공 ≠ 검증 통과. 상태는 `RUN_COMPLETED` / `RUN_HEALTHY` / `VERIFIED` / `VALIDATED` / `FAILED_*` 로 구분.
2. 통과 기준은 실행 전 커밋으로 잠그고, 결과를 본 뒤 완화하지 않음.
3. 개발용 임시 입력(`cases/dev/`, `DEV_`)과 논문 조건(`cases/paper/`, 해시 잠금)을 분리.
4. 원문을 확인하지 않은 문헌 수치는 통과 기준으로 쓰지 않음.
