# 05. 미결정 항목

상태: `지금 결정` = 구현 착수 전에 필요 / `단계 전 결정` = 해당 단계 진입 전 / `나중` = 논문 조건 확정 시.
"권고"는 설계자의 제안이며 확정이 아닙니다.

## A. 지금 결정해야 하는 기술 선택

| ID | 항목 | 선택지 | 권고 | 영향 |
|---|---|---|---|---|
| D-A1 | 주 수치해석 방법 | (A) FV + 기하 VOF + 날카로운 IBM / (B) 다상 WCSPH | **(A)** — 근거 `02_design_document.md` §2 | 전체 구조 |
| D-03 | 공기 압축성 | 비압축 공기 / 압축성 공기(등엔트로피 또는 등온) + 비압축 물 / 두 상 모두 압축성 | **압축성 공기 + 비압축 물**, 압력 방정식에 ψ 항을 처음부터 포함 (ψ=0 으로 비압축 검증 가능). 물 압축성은 ρ_w c_w V 상한 감시로 대체 | 평평한 바닥 첨두압력 |
| D-04 | 이동 경계 처리 | 날카로운 IBM 단독 / IBM + 물체 고정 좌표계 교차검증 모드 / 이동 적합 격자 | **IBM + 물체 고정 좌표계 교차검증 모드** (후자는 축대칭 지정운동 한정) | 압력 정확도 검증 가능성 |
| D-07 | 언어·라이브러리 | C++17 / Fortran / Python+Numba. Poisson: hypre·PETSc / 자체 다중격자 | **C++17 + CMake + OpenMP**, 3D 에서 MPI. Poisson 은 2D 에서 자체 기하 다중격자 또는 PETSc (워크스테이션 설치 상태에 따라). 후처리·판정은 Python | 개발 속도, 3D 확장성 |
| D-06 | 구조 모델 | 축대칭 고체 FE / 축대칭 쉘 FE / 상용 FE 사용 | **자체 축대칭 고체 FE**, 상용 FE 가 있으면 교차검증 (4-D) | 접합부 응력 정확도 |
