## 1. 문제 정의

### 1.1 확정 조건

| 항목 | 내용 |
|---|---|
| 물체 | 속이 빈 원통, 하단은 평평한 바닥판으로 막힘 (컵 형상) |
| 자세 | 원통 축이 수직, 바닥판부터 입수 |
| 출력 | 압력 분포 p(r,t), 충격력 F(t), 충격량 I(t), 구조응력 σ(x,t)의 시간 이력 |
| 1차 버전 | 2차원 축대칭 (r–z), 정수면 입수 |
| 최종 확장 | 3차원, 규칙파 중 입수 |
| 실행 환경 | 워크스테이션 (사양 미확인 — `01_environment_check.md`) |
| 미정 | 치수, 두께, 재료, 전체 질량, 입수 속도 |

### 1.2 물리적 특징 (설계를 결정짓는 요소)

1. **바닥이 평평함(데드라이즈각 0°).** 비압축 포텐셜 이론(Wagner형)은 데드라이즈각 β → 0에서 압력이 발산합니다 [R-02, R-03]. 실제로는 바닥판과 수면 사이에 **공기가 포획되어 완충**되며, 실험 최대압력은 공기를 무시한 이론보다 훨씬 작게 측정됩니다 [R-05, R-06, R-11]. 따라서 **공기상(air phase)을 직접 계산하는 2상 해석이 필수**이고, 결과는 공기층 해상도에 민감합니다.
2. **물의 압축성 상한.** 공기와 물을 모두 무시하면 압력에 상한이 없지만, 물리적으로는 음향 임피던스 한계 p ≤ ρ_w c_w V (water-hammer 압력)가 존재합니다. 입수 극초기에는 물의 압축성이 지배적인 단계가 있습니다 [R-13].
3. **원통 측벽.** 바닥판 가장자리에서 물이 박리되어 측벽을 따라 제트/분무가 생깁니다. 측벽에는 수평 압력(원주 응력 유발)과 전단이 작용합니다.
4. **내부 공기.** 원통 내부는 상단이 열려 있다면 대기압 공기입니다. 바닥판 내측면 압력은 대기압으로 둘 수 있으나, 상단 개방 여부는 미결정입니다 (`05_open_decisions.md` D-12).
5. **구조.** 바닥판은 충격 시간 규모와 고유주기가 비슷할 수 있어 동적 응답(동적 증폭)이 중요하며, 바닥판–측벽 접합부에 응력 집중이 생깁니다.

## 2. 수치해석 방법 비교 (2개)

후보는 슬래밍 문헌에서 널리 쓰이는 두 계열로 한정했습니다.

- **방법 A — 고정 격자 유한체적(FV) 2상 비압축/약압축 해석 + 기하학적 VOF + 날카로운 경계(sharp-interface) 가상경계법(IBM)**
  엇갈림(MAC) 격자, 투영법(projection), 기하학적 VOF [R-07, R-08], 컷셀/고스트셀 IBM [R-09, R-10].
- **방법 B — 약압축성 SPH (WCSPH, 다상)**
  입자법, 상태방정식으로 압력 계산, 물체는 경계입자.

### 2.1 비교표

| 관점 | 방법 A: FV + 기하 VOF + 날카로운 IBM | 방법 B: 다상 WCSPH |
|---|---|---|
| 구현 난도 | 높음. 축대칭 기하 VOF 재구성, 컷셀 IBM, 변수밀도 Poisson이 핵심 난관. 단, 각 구성요소가 독립적으로 시험 가능 | 기본 알고리즘은 단순. 그러나 **축대칭 SPH**는 축 근처 커널 보정이 필요해 비표준이며, 다상(밀도비 1000) 안정화와 압력 잡음 억제가 별도 난관 |
| 충격압력 정확도 | 비압축 압력이 Poisson 해로 매끈하게 나옴. 날카로운 IBM이면 벽면 압력을 직접 얻음. 첨두값은 격자 의존적이므로 격자 수렴과 유한 센서 면적 평균이 필요 | 상태방정식 기반 압력은 고주파 잡음이 커서 필터링(δ-SPH 등)이 필수. 첨두값이 필터·인공음속에 의존 → 정량 압력 이력에 불리 |
| 질량보존 | 기하 VOF는 원리적으로 이산 체적 보존 (데카르트 격자). **축대칭에서는 r-가중 체적 때문에 보존이 자동이 아니며 별도 처리 필요** (§3.2) | 입자 질량이 고정이므로 질량은 정확히 보존. 대신 밀도 변동(약압축)이 부피 오차로 나타남 |
| 계산 비용 | 공기층 해상을 위해 바닥판 근처 국소 세분화 필요. 축대칭 2D는 워크스테이션에서 충분. Poisson 해법이 비용의 대부분 | 인공음속에 묶인 작은 Δt + 공기상 입자까지 필요 → 공기 완충 해석에 비용이 큼. 국소 세분화가 어렵다 |
| 축대칭 구현 | 체적·면적에 r 가중만 넣으면 됨 (FV에서 자연스러움). 축(r=0)은 대칭 경계 | 축대칭 SPH 정식화가 필요하고 축 근처 오차가 알려진 문제. 사실상 3D로 푸는 경우가 많음 |
| 3차원 확장 | 동일 알고리즘이 데카르트 3D로 그대로 확장. 규칙파 생성/흡수도 FV에서 표준적. MPI 영역분할 용이 | 3D가 자연스러움. 다만 3D 다상 + 공기 완충은 입자 수가 매우 큼 |
| 공기 압축성 포함 | 압력 방정식에 압축 항을 추가해 공기만 압축성으로 다루기 용이 | 상태방정식으로 자연스럽게 포함되나, 물의 인공음속을 낮게 잡으면 물 압축성이 비물리적으로 커짐 |

### 2.2 권고안

**방법 A를 채택할 것을 권고합니다.**

근거 요약:
1. 목표 출력이 **정량적 압력 시간 이력**이고, 평평한 바닥에서는 공기 완충이 결과를 지배합니다. 공기층 국소 세분화와 매끈한 압력장이 필요한데, 방법 A가 유리합니다.
2. 1차 버전이 **축대칭**입니다. FV는 r-가중으로 축대칭을 자연스럽게 다루지만 SPH는 그렇지 않습니다.
3. 최종 확장(3D 규칙파)에서도 같은 알고리즘·같은 검증 체계를 유지할 수 있습니다.

방법 A의 알려진 위험과 대응:

| 위험 | 대응 |
|---|---|
| 밀도비 1000에서 경계면 근처 운동량 오차·불안정 | 질량·운동량을 같은 VOF 플럭스로 수송하는 일관(consistent) 수송 방식 채택 (구체 문헌은 미확인 — 구현 전 확인) |
| 축대칭 VOF 체적 보존 | §3.2의 r-가중 체적 계산, 단계 2 검증에서 보존 오차를 독립 지표로 감시 |
| IBM 경계에서 압력 정확도 | 확산형(diffuse) 강제항이 아닌 날카로운 컷셀/고스트셀 방식. 지정 운동 물체의 부가질량 해석해로 검증 (단계 1-E) |
| 물체 이동 시 새로 드러나는 셀(freshly cleared cells)의 압력 진동 | 한 시간 간격당 물체 이동량 < 셀 크기의 일정 비율로 제한 (§3.6) + 진동 크기 감시 |

교차검증용 보조 수단: 축대칭 1차 버전에 한해 **물체 고정 좌표계(body-fixed frame) + 물체 적합 격자** 모드를 함께 둘 것을 권합니다. 순수 수직 병진이므로 가속 좌표계의 관성력 −dV/dt만 추가하면 되고, IBM 없이 벽면 압력을 얻을 수 있어 IBM 오차를 독립적으로 분리할 수 있습니다. (이는 별도 방법이 아니라 같은 FV 솔버의 경계 처리 옵션입니다. 채택 여부는 D-04.)

## 3. 항목별 처리 방법과 한계

### 3.1 지배방정식과 축대칭 항

**방정식.** 단일유체(one-fluid) 정식화, 물·공기 공통 속도장 u = (u_r, u_z), 회전(swirl) 성분 없음 (u_θ = 0).

- 연속: 공기 압축성 미포함 시 ∇·u = 0. 포함 시 (1/(ρc²)) Dp/Dt + ∇·u = 0 (공기 영역에만 압축률 ψ = 1/(ρc²) ≠ 0, 물은 ψ = 0 또는 선택적으로 매우 작은 값).
- 운동량: ρ(∂u/∂t + u·∇u) = −∇p + ∇·[μ(∇u + ∇uᵀ)] + ρg (+ 선택: 표면장력)
- 물성: ρ = αρ_w + (1−α)ρ_a, μ = αμ_w + (1−α)μ_a (α: 물 체적분율)

**축대칭 항 (원통좌표 r–z).**
- 발산: ∇·u = (1/r) ∂(r u_r)/∂r + ∂u_z/∂z
- r 방향 운동량의 점성항에 −2μ u_r / r² 항이 추가됨 (원주 방향 변형률 u_r/r 때문)
- 대류항: u_θ = 0이므로 원심항 u_θ²/r는 0
- 유한체적: 셀 체적 V = π(r_e² − r_w²)Δz, r면 면적 A = 2π r_f Δz, z면 면적 A = π(r_e² − r_w²). 즉 **2π 를 포함한 실제 체적/면적**을 쓰면 축대칭 항이 이산 보존형으로 자연히 들어갑니다.
- 축(r = 0): u_r = 0, ∂(·)/∂r = 0 대칭 조건. r = 0 면의 면적이 0이므로 플럭스가 자동으로 0.

**한계.**
- 축대칭은 비축대칭 교란(측벽 제트의 3차원 불안정, 공기 포켓의 비대칭 붕괴, 실험의 미세한 경사)을 표현하지 못합니다. 평평한 바닥판 실험은 미세 경사에 매우 민감하다고 보고되어 있으므로 [R-12: 0°–4° 경사에서 압력 이력 유형이 바뀜], 축대칭 결과는 "완전한 수평 입수"라는 이상화의 결과입니다.
- 난류 모델 없음. 충격 시간 규모에서 관성 지배이므로 점성은 2차적이라고 가정합니다 (가정이며, 점성 계수를 바꾼 민감도 시험으로 확인 — 단계 3).
- 표면장력은 1차 버전에서 제외 (Weber 수가 크다는 가정. 입력 결정 후 Weber 수로 재확인 — D-10).

### 3.2 공기와 물, 자유수면

**처리.** 기하학적 VOF (PLIC 재구성 + 방향분할 또는 비분할 기하 수송). isoAdvector [R-08] 계열도 후보입니다. 대수적(algebraic) VOF는 경계면이 번져 공기층 두께를 과대평가하므로 1차 후보에서 제외합니다.

**축대칭 특수성.** 같은 α라도 셀 안 위치에 따라 r-가중 체적이 달라지므로, PLIC 선분 위치를 "면적 분율"이 아닌 **r-가중 체적 분율**로 결정해야 합니다. 플럭스 체적도 r-가중으로 계산합니다. 이를 지키지 않으면 축 근처에서 질량이 체계적으로 생성/소멸합니다.

**공기 압축성.** 공기는 이상기체·등엔트로피(폴리트로프 지수 κ, D-03) 압축성으로, 물은 비압축으로 두는 것을 기본안으로 합니다.
- 근거: 평평한 바닥 입수에서는 공기층의 압축이 첨두압력과 압력 진동(공기 포켓 맥동)을 지배합니다 [R-05, R-06, R-11]. 공기를 비압축으로 두면 공기는 순간적으로 빠져나가야 하므로 완충 효과를 왜곡할 수 있습니다.
- 구현: 압력 방정식에 ψ ∂p/∂t 항이 들어가는 압력기반(pressure-based) 형태. ψ = 0으로 두면 비압축 솔버로 환원되므로, 비압축 검증(단계 1–2)과 같은 코드를 씁니다.

**한계.**
- 물의 압축성을 무시하면 극초기 음향 단계(공기가 거의 없는 접촉점 근처)의 압력을 표현하지 못합니다 [R-13]. 대신 계산된 압력이 ρ_w c_w V를 넘으면 **모델 적용 범위 이탈 신호**로 처리합니다 (§3.3).
- 포기(aeration)된 물, 기포 분열, 미세 분무는 격자보다 작으면 표현 불가. 포기 효과는 첨두하중을 크게 바꾼다고 보고되어 있으므로 [R-14] 논문 조건은 "포기되지 않은 물"로 명시해야 합니다.
- 공기층이 격자 몇 개 두께로 얇아지면 결과가 격자 의존적이 됩니다. 이 때문에 첨두압력 자체보다 **충격량과 공간 평균 압력**을 주 지표로 삼습니다 (§3.7).

### 3.3 평평한 바닥의 입수와 공기 포획

**예상 현상 순서 (지정 속도 V, 정수면).**
1. 접근: 바닥판 아래 공기가 압축되며 바깥으로 밀려나고, 공기 압력이 수면을 오목하게 누름.
2. 접촉: 수면이 바닥판 가장자리 부근에서 먼저 닿아 중앙에 공기 포켓 포획.
3. 압축/맥동: 포획된 공기 포켓이 압축·팽창을 반복하며 압력이 진동.
4. 가장자리 박리와 제트: 바닥판 모서리에서 유동이 박리, 측벽을 따라 제트.
5. 침수 이후: 부가질량 지배 하중 → 항력/정수압 하중으로 전이.

**처리.**
- 바닥판 아래와 모서리 주변을 국소 세분화. 초기 간격(바닥판–수면 거리)은 입력 결정 항목이며, **결과가 초기 간격에 의존하지 않을 만큼 충분히 멀리서 출발**해야 합니다. 이를 시험으로 확인합니다 (단계 3-C).
- 출력에 공기 포켓 지표를 포함: 포획 공기 체적 V_pocket(t), 포켓 평균 압력, 포켓 반경.
- 물리적 상한 감시: max p ≤ ρ_w c_w V. 초과 시 해당 실행 결과를 "적용 범위 밖"으로 표기 (실패를 숨기지 않음).

**한계.**
- 포획 공기 포켓 크기와 첨두압력은 초기 수면 상태(미세 파, 진동), 물체 경사, 공기의 열역학(등온/단열)에 민감합니다. 이 민감도는 실험 간에도 큰 산포로 나타나므로, 첨두압력 검증 기준은 실험 산포를 반영해야 합니다 (`03_verification_plan.md`).
- 수치 공기층 붕괴(층 두께 < 2–3 셀)는 수치적으로 포켓을 "잘못" 소멸시킬 수 있습니다. 공기층 두께 대비 셀 크기를 로그로 남겨 판단합니다.

### 3.4 이동하는 물체 경계

**기본안: 날카로운 경계 IBM (컷셀 또는 고스트셀).**
- 물체 형상: 축대칭 단면(바닥판 + 측벽)을 부호거리함수(SDF)로 표현. 3D 확장 시 같은 SDF를 회전체로 생성.
- 경계조건: 물체 표면에서 유체 속도 = 물체 속도 (점착, no-slip). 압력은 Neumann 조건 ∂p/∂n = −ρ (Du_body/Dt)·n 의 이산 형태와 일관되게 처리.
- 지정 운동: z_b(t), V(t), a(t)를 입력 함수로 받음 (상수 속도, 감속 프로파일, 실험 측정 이력 재생).
- 자유 운동: 6자유도 중 축대칭에서는 수직 병진 1자유도만. 3D에서 확장.

**보조안: 물체 고정 가속 좌표계 + 물체 적합 격자 (축대칭 지정운동 교차검증용, D-04).**

**한계.**
- 원통 두께 t_w가 셀 크기의 몇 배 이하이면 IBM으로 내벽/외벽을 구분하지 못합니다. **측벽 두께를 최소 3–4셀 이상으로 해상**하거나, 그보다 얇으면 "두께 0 벽"으로 다루는 별도 처리가 필요합니다 (D-05).
- 새로 드러나는 셀의 압력 스파이크는 IBM의 알려진 수치 아티팩트입니다. 압력 이력에 격자 주기로 반복되는 스파이크가 있으면 물리가 아닌 수치 잡음으로 판정하고 별도 보고합니다.

### 3.5 압력과 속도의 결합

**처리.** 엇갈림(MAC) 격자 + 분수단계(fractional-step) 투영법.
1. 예측: 대류·점성·중력으로 중간 속도 u*.
2. 압력: ∇·((1/ρ) ∇p^{n+1}) − ψ (p^{n+1} − p^n)/Δt² = ∇·u*/Δt (ψ = 0이면 비압축).
3. 보정: u^{n+1} = u* − (Δt/ρ) ∇p^{n+1}.
- 밀도는 면(face)에서 VOF 기반으로 평가하고, 중력·압력 구배를 같은 면 위치에서 평가하는 균형력(balanced-force) 배치를 사용 → 정수압 상태에서 허위 속도 최소화.
- Poisson 해법: 밀도비 1000의 가변계수 문제 → 대수 다중격자(AMG) 전처리 + Krylov (외부 라이브러리 hypre/PETSc 또는 자체 기하 다중격자, D-07). 수렴 기준은 잔차의 상대 감소량과 **이산 발산의 최대값**을 함께 사용.
- 시간 정확도: 2차 (예: 대류 Adams–Bashforth/RK2, 점성 Crank–Nicolson 또는 명시). 2차 정확도는 단계 1에서 실측으로 확인.

**한계.**
- 투영법의 분할 오차로 벽면 압력이 1차 시간정확도로 떨어질 수 있습니다 (경계조건 처리에 의존). 단계 1-E에서 가속 물체의 압력·힘 시간 수렴 차수를 별도로 확인합니다.
- Poisson 해법의 수렴 허용치가 느슨하면 질량 오차가 압력 잡음으로 나타납니다. 허용치는 결과 민감도로 결정하고 기록합니다.

### 3.6 시간 간격 제한과 수치적 안정성

Δt = min(Δt_CFL, Δt_visc, Δt_grav, Δt_body, Δt_cap, Δt_out), 각 제한:

| 제한 | 식 (개략) | 비고 |
|---|---|---|
| 대류 CFL | Δt ≤ C · Δx / max|u| | **제트 속도는 입수 속도보다 훨씬 클 수 있음** → 최대값은 물체 속도가 아니라 유동장 전체에서 계산. 기하 VOF는 C ≤ 0.5 권장(방향분할 시) |
| 점성 (명시 처리 시) | Δt ≤ C_v · ρ Δx² / μ | 공기상(μ/ρ가 큼)에서 지배적일 수 있음 → 암시 처리 고려 |
| 중력파 | Δt ≤ C · sqrt(Δx / g) | 대개 비지배적 |
| 물체 이동 | Δt ≤ C_b · Δx / |V_body| (C_b ≤ 0.5 권장) | IBM 새 셀 문제 완화 |
| 표면장력 (포함 시) | Δt ≤ sqrt(ρ̄ Δx³ / (2πσ)) | 1차 버전 제외 |
| 공기 압축성 | 압력 암시 처리 시 음향 CFL은 안정성 제한 아님 | 대신 **공기 포켓 맥동 주기당 최소 20스텝** (정확도 기준, 수렴 시험으로 확정) |
| 출력 해상도 | 압력 상승 시간 당 최소 N개 샘플 | N은 단계 3 시간 수렴 시험으로 확정 |

안정성 감시 (모든 실행에서 자동 기록):
- 이산 발산 최대값, 전체 물 체적 변화, 운동에너지, α의 범위 위반 (α < 0 또는 > 1의 크기)
- 이 값이 임계를 넘으면 **"실행은 완료되었으나 신뢰 불가"** 로 표시 (§5).

### 3.7 압력 적분을 통한 충격력과 충격량

**충격력.** 물체 표면 S(t)에서
F(t) = ∮_S [−(p − p_ref) n + τ·n] dA

- 축대칭 바닥판(외면, 반경 a): F_z^bottom(t) = 2π ∫_0^a (p(r,t) − p_in) r dr (p_in: 원통 내부 압력, 개방 시 대기압)
- 측벽: 압력의 수평 성분은 축대칭에서 합력 0이지만, **원주 응력(구조) 계산에는 필요** → 별도 출력. 측벽 전단의 수직 성분은 F_z에 포함.
- 기준압력 p_ref: 대기압. 정수압 성분을 포함한 전체 하중과 정수압을 뺀 "충격 성분"을 모두 출력.

**충격량.** I(t) = ∫_{t0}^{t} F_z(t') dt' (사다리꼴 또는 유체 시간 간격에 일관된 적분). 적분 시작 t0 정의(첫 접촉 시점 또는 공기 압력이 기준 이상으로 오른 시점)를 고정해 기록합니다.

**압력 "센서" 출력.** 점값 첨두압력은 격자 의존적이므로, 실험 센서와 같은 유한 면적(직경 d_s, D-09)에 대한 **면적 평균 압력**을 주 출력으로 하고 점값은 보조로 남깁니다. 실험에서 측정된 첨두값이 센서 크기에 의존한다는 점과 정합시키기 위함입니다.

**독립 검사 (적분 오류 탐지).**
- 표면 적분 힘 vs 제어체적 운동량 수지(유체 영역 전체 운동량 변화 + 경계 플럭스) — 두 값의 차이를 모든 실행에서 기록.
- 자유 운동 시: m ΔV = ∫(F_z − m g) dt 의 일치.
- 완전 침수 후 지정 등속 운동: 충격량 ≈ 부가질량 × V의 크기 수준인지 확인 (원판의 무한유체 부가질량 (8/3)ρa³ [R-21]; 자유수면 위 원판에서 그 절반이라는 값은 **문헌 원문 미확인** → 사용 전 확인 필요).

**한계.** 첨두 힘보다 충격량이 격자·공기 모델에 덜 민감할 것으로 예상하며, 이는 포기수 실험에서 충격량 변동이 첨두하중 변동보다 작았다는 보고와 정합적입니다 [R-14]. 다만 이 예상 자체를 단계 3에서 확인해야 합니다.

### 3.8 유체 압력을 구조 모델로 전달하는 방법

**처리 (단방향).**
1. 유체 측: 매 유체 시간 간격마다 물체 표면 샘플점(구조 표면 절점 위치에 대응)의 압력·전단을 저장. 저장 형식은 시간 이력 파일 (HDF5 또는 이진, D-08).
2. 공간 사상: 구조 표면 요소의 형상함수 N_i 에 대해 **일관 절점력** f_i(t) = ∫ N_i (−p n + τ·n) 2πr ds. 유체 표면 분포는 구조 요소 내 가우스점으로 보간.
3. 보존 검사: Σ f_i = 유체 측 적분 F(t) (상대오차 ≤ 1e−6 수준을 목표, 기준은 단계 5에서 확정), 충격량도 동일.
4. 시간 사상: 구조 시간 간격 Δt_s가 유체 Δt_f보다 크면 Δt_s 구간의 **평균(충격량 보존)** 으로 전달, 작으면 선형 보간. 단순 샘플링(aliasing)은 금지.
5. 내부면: 바닥판 내측면·측벽 내측면에는 내부 공기압(대기압)을 적용.

**한계.**
- 단방향이므로 구조 변형이 유동(특히 공기 포켓 체적)을 바꾸는 효과는 없음 (§3.10).
- 유체 IBM 표면과 구조 표면이 기하학적으로 정확히 일치하지 않음(격자 해상도 차이) → 사상 오차를 보존 검사로 정량화.

### 3.9 구조 관성과 동적 응답

**구조 모델 기본안: 축대칭 고체 유한요소 (r–z 단면, 2차 사각형 요소), 선형 탄성, 소변형.**
- 이유: 바닥판–측벽 접합부의 응력 집중과 두꺼운 판의 전단 변형을 별도 이론 없이 표현. 판/쉘 요소는 접합부 처리에 추가 가정이 필요.
- 대안: 축대칭 쉘 요소 (바닥판 = 원판, 측벽 = 원통 쉘). 계산은 빠르나 접합부 응력은 근사. 교차검증용으로 고려 (D-06).
- 운동방정식: M ü + C u̇ + K u = f(t). 시간적분 Newmark 평균가속도법(무조건 안정, 수치 감쇠 없음). 고주파 잡음이 문제되면 HHT-α. 감쇠 C는 Rayleigh 감쇠, 계수는 재료/실험 근거로 결정 (D-02).
- 관성: 일관 질량행렬. 축대칭 질량에 2πr 가중.
- 출력: 변위, 속도, 가속도, 응력 성분(σ_rr, σ_zz, σ_θθ, σ_rz), von Mises 응력의 시간 이력과 위치별 최대값. 응력은 요소 적분점 → 절점 회복 방식 명시.
- 3D 확장: 비축대칭 파랑 하중 → 쉘 요소 3D 모델 또는 원주 푸리에 분해(Fourier-decomposed axisymmetric) 모델 (D-06).

**강체 운동과 탄성 응답 분리.**
- 지정 운동: 구조는 지정 운동을 따른다고 보고, 구조 좌표계에서 관성력 −ρ_s a(t) 를 체적력으로 가함. 지지 조건(구동 장치 부착 위치)은 실험 장치에 따라 달라짐 → D-11.
- 자유 운동: 자유-자유 구조. 관성 해제(inertia relief) — 강체 가속도를 유체 합력에서 구해 d'Alembert 력으로 가함. 강체 모드 특이성 처리 필요.

**한계.** 선형 탄성·소변형 가정. 소성, 좌굴, 대변형은 범위 밖입니다 (재료 결정 후 응력 수준으로 재판단). 건조(dry) 고유진동수로 응답하므로 부가질량에 의한 고유진동수 저하가 반영되지 않습니다 (§3.10).

### 3.10 단방향 연성이 유효한 조건

단방향 연성 = 유체 해석은 강체로, 구한 하중을 구조에 가함. 아래 조건을 **사전에 정한 기준으로 사후 점검**하고, 하나라도 위반하면 해당 결과에 "단방향 가정 위반"을 표기합니다.

| 조건 | 지표 | 근거 |
|---|---|---|
| (1) 구조 변형 속도가 입수 속도보다 충분히 작음 | max|ẇ| / V | 경계조건에 들어가는 속도가 크게 바뀌지 않아야 함. 수탄성 효과가 클 때 판 응력이 입수 속도에 선형 비례하는 거동이 보고되어 있음 [R-15] |
| (2) 변형에 의한 체적 변화가 포획 공기 체적보다 충분히 작음 | ΔV_defl / V_pocket | 평평한 바닥 특유. 공기 포켓 압력은 체적 변화에 민감하므로 (1)보다 엄격할 수 있음 |
| (3) 하중 지속시간과 구조 습윤(wet) 고유주기의 비 | T_load / T_wet | 비가 크면 준정적, 작으면 충격량 지배. 중간 영역에서 동적 증폭 최대 — 이 비 자체가 연성 필요성의 판단 근거 (일반 구조동역학 결과) |
| (4) 부가질량에 의한 고유진동수 변화 | f_wet / f_dry | 단방향은 건조 고유진동수로 응답. 차이가 크면 응답 주기·첨두가 틀림 |
| (5) 변위 크기가 유체 격자 크기보다 작음 | max|w| / Δx_min | 크면 유체 해석의 형상 자체가 달라짐 |

임계값은 검증 계획 단계 5에서 **실행 전 고정**합니다. 위반 시 대응은 양방향 연성(분할형, 강결합 반복)인데, 가벼운 구조·큰 부가질량 조합에서 느슨한 분할형 연성은 수치 불안정이 알려져 있으므로 [R-16] 강결합 반복이 필요합니다. 양방향 연성은 이번 범위 밖이며 D-13으로 남깁니다.

- 좌표계는 컴파일 타임 또는 실행 시 옵션으로 `planar2D`, `axisym`, `3D`. **planar2D는 2D 쐐기 입수 문헌 비교를 위해 필수**입니다 (단계 3-A).
- 언어/라이브러리는 D-07 (권고: C++17 + CMake + OpenMP, 3D 단계에서 MPI. 후처리·판정은 Python).

## 5. 실행 성공과 물리 검증 통과의 구분

모든 실행 결과에 아래 상태 중 하나를 기록합니다. 상위 상태는 하위 상태를 포함하지 않습니다 (각각 별도 판정).

| 상태 | 의미 | 판정 주체 |
|---|---|---|
| `RUN_COMPLETED` | 계산이 종료 시각까지 NaN/발산 없이 끝남 | 자동 |
| `RUN_HEALTHY` | 위에 더해 감시 지표(발산, 체적 보존, α 범위, 운동량 수지 차이)가 사전 임계 내 | 자동 |
| `VERIFIED` | 해석해/제조해 대비 오차와 수렴 차수가 사전 기준 통과 | 판정 스크립트 + 기록 |
| `VALIDATED` | 실험/문헌 대비 비교 오차가 사전 기준(불확도 포함) 통과 | 판정 스크립트 + 기록 |
| `FAILED_<사유>` | 사전 기준 불통과. 결과와 사유를 그대로 보존 | — |

규칙:
1. **"코드가 돌았다"(`RUN_COMPLETED`)는 검증 결과가 아닙니다.** 보고서와 논문에는 `VERIFIED`/`VALIDATED` 판정을 받은 구성만 사용합니다.
2. 판정 기준은 해당 단계 실행 **전에** `03_verification_plan.md`에 기록하고 git 커밋으로 고정합니다. 커밋 해시를 판정 기록에 남깁니다.
3. 기준을 바꿔야 할 정당한 이유(참조 데이터 오류 발견, 불확도 재평가 등)가 생기면, 변경 사유·날짜·변경 전 결과를 함께 남기고 **변경 전 기준에 의한 판정(불통과)을 삭제하지 않습니다.** 결과를 본 뒤 기준을 완화해 통과시키는 것은 금지합니다.
4. 실패한 시험은 숨기지 않고 `FAILED_*`로 남깁니다.

## 6. 입력값 관리 — 개발용 임시값과 논문 조건의 분리

| 구분 | 위치 | 규칙 |
|---|---|---|
| 검증용 | `cases/verification/` | 해석해/문헌 조건 그대로. 무차원 또는 문헌 단위 |
| 개발용 임시 | `cases/dev/` | 파일명 `DEV_` 접두어, 입력 파일에 `purpose: development` 필수. 결과 파일 머리말과 그림에 "DEV — 논문 조건 아님" 워터마크 |
| 논문 조건 | `cases/paper/` | `purpose: paper`, 입력 확정 시 해시 기록(잠금). 해시 불일치 또는 `purpose` 누락 시 솔버가 `results/paper/`로의 출력을 거부 |

- 개발용 임시값은 실제 논문 후보값과 일부러 다르게(예: 둥근 무차원 값) 잡아 혼동을 막습니다.
- 모든 결과 파일에 입력 파일 해시, 코드 커밋 해시, 실행 일시, 격자/시간 간격 정보를 메타데이터로 기록합니다.
