# 04. 개발 단계표

원칙: 각 단계는 **"구현 완료"와 "검증 통과"를 별개 체크항목**으로 둡니다. 다음 단계 진입 조건은 이전 단계의 *검증 통과*입니다 (실행 성공만으로는 진입 불가).
검증 ID 는 `03_verification_plan.md` 를 따릅니다.

| 단계 | 구현 내용 | 산출물 | 진입 조건 | 종료 조건 (검증) | 선행 결정 |
|---|---|---|---|---|---|
| P0 | 저장소 구조, 빌드 체계, 입력 검증기(purpose/해시 잠금), 메타데이터·판정 기록 틀 | 빈 솔버 골격, 입력 스키마, 판정 기록 템플릿 | 설계 승인, 워크스테이션 사양 확인 | 개발용 입력으로 `results/paper/` 출력이 거부되는지 시험 | D-07, D-08 |
| P1 | 격자(균일 + 국소세분화), 좌표계(planar2D/axisym), 단상 투영법, 변수밀도 Poisson | 단상 솔버 | P0 | 1-A, 1-B, 1-C, 1-D 통과 | D-07 |
| P2 | SDF 형상, 날카로운 IBM, 지정 운동, 표면 적분, (선택) 물체 고정 좌표계 모드 | 이동 물체 단상 솔버 | P1 통과 | 1-E, 1-F, 1-G, (1-H) 통과 | D-04, D-05 |
| P3 | 기하 VOF (r-가중), 일관 질량–운동량 수송, 공기 압축성 항 | 2상 솔버 | P1 통과 (P2와 병행 가능) | 2-A ~ 2-G 통과 (2-D/2-E 는 정성) | D-03 |
| P4 | 2상 + IBM 통합, 공기 포켓 진단 출력, 면적평균 압력 센서, 운동량 수지 검사 | 지정 운동 입수 솔버 | P2, P3 통과 | 3-A, 3-C, 3-D, 3-F, 3-G 통과. 3-B/3-E/3-I 보고. 3-H 는 데이터 확보 시 | D-09, D-14 |
| P5 | 축대칭 고체 FE, Newmark/HHT, Rayleigh 감쇠, 관성력/관성 해제 | 구조 동해석기 (독립 실행) | P0 (P1–P4와 병행 가능) | 4-A, 4-B, 4-E ~ 4-H 통과. 4-C/4-D 는 출처·도구 확보 시 | D-02, D-06, D-11 |
| P6 | 하중 사상(공간·시간), 단방향 연성 파이프라인, 유효성 지표 자동 산출 | 단방향 연성 해석 | P4, P5 통과 | 5-A ~ 5-D 통과. 5-E 정성 보고 | D-15 |
| P7 | 1자유도 자유 운동, 유체–강체 연성(필요 시 강결합 반복) | 자유 낙하 입수 해석 | P4 통과 | 6-A, 6-B, 6-D, 6-E, 6-F 통과 | D-01 |
| P8 | 워크스테이션 빌드로 단계 1–6 검증 재실행, 논문 조건 확정·잠금, 수치 불확도 평가, 결과 산출 | 논문용 결과 | P6 (및 자유운동 사용 시 P7) 통과, 입력 확정, **워크스테이션에서 검증 재실행 통과** | 논문 조건에서 3-C 수준 수렴 시험 재수행, 단방향 유효성 지표 보고 | D-01, D-02 등 입력 전반 |
| P9 (확장) | 3D 데카르트, MPI, 규칙파 생성·흡수, 6자유도, 3D 구조 | 3D 파랑 중 입수 솔버 | P8 | 7-A ~ 7-E | D-16 |

## 병행 가능성

```
P0 ─ P1 ─┬─ P2 ─┐
         └─ P3 ─┴─ P4 ─┬─ P6 ─ P8 ─ P9
P0 ─ P5 ───────────────┘    │
                    P4 ─ P7 ┘
```

## 각 단계 공통 완료 체크리스트

- [ ] 구현 완료 (코드 리뷰)
- [ ] 단위 시험 통과 (실행 성공 수준)
- [ ] 해당 검증 시험의 통과 기준이 **실행 전에** 커밋되어 있음 (커밋 해시 기록)
- [ ] 검증 시험 실행, 판정 기록 작성 (통과/불통과 모두)
- [ ] 불통과 항목이 있으면 원인 분석 기록. 기준 변경 시 사유·변경 전 판정 보존
