# 03. 단계별 검증 계획

문서 상태: 초안 v0.1. **각 단계의 통과 기준은 해당 단계의 첫 실행 전에 사용자 승인 후 커밋으로 잠급니다.** 아래 수치 중 "잠정"으로 표시된 것은 아직 잠기지 않은 제안값입니다.
문헌 `[R-xx]`의 확인 수준은 `06_references.md` 참고. "미확인"으로 표시된 자료는 확인 전까지 통과 기준의 근거로 쓰지 않습니다.

---

## 0. 공통 원칙

### 0.1 검증(Verification)과 확인(Validation)의 구분
- **검증(코드 검증, VERIFIED):** 방정식을 맞게 풀었는가. 해석해·제조해(MMS) 대비 오차와 수렴 차수로 판정 [R-27].
- **확인(물리 검증, VALIDATED):** 맞는 방정식을 풀었는가. 실험/문헌 대비 비교 오차를 수치·입력·실험 불확도와 함께 판정 [R-28].
- **실행 성공(RUN_COMPLETED/RUN_HEALTHY)은 위 둘 어느 것도 아닙니다** (`02_design_document.md` §5).

### 0.2 통과 기준의 근거 유형
각 기준에는 아래 근거 유형 중 하나를 명시합니다.

| 기호 | 근거 유형 | 설명 |
|---|---|---|
| (T) | 이론적 수렴 | 이산화의 형식 차수 p_f. 관측 차수 p_obs 가 점근 영역에서 p_f 에 근접해야 함 |
| (U) | 불확도 기반 | 비교 오차 E = S − D 를 검증 불확도 u_val = sqrt(u_num² + u_input² + u_D²) 와 비교 [R-28]. u_num 은 GCI 등 격자 수렴으로 추정 [R-25, R-26] |
| (P) | 물리적 한계/보존 | 보존 법칙, 물리적 상한 (예: ρ_w c_w V). 위반은 곧 오류 |
| (C) | 관례값 | 문헌 근거가 아닌 공학적 관례. **관례임을 명시**하고 실행 전 잠금 |

### 0.3 수렴 시험 공통 절차
- 최소 3개 격자, 균일 세분화비 r ≥ 1.3 (잠정, (C)) [R-25].
- 시간 간격도 같은 방식으로 3단계.
- 관측 차수 p_obs, Richardson 외삽값, GCI 를 함께 보고. 진동 수렴/발산하는 경우 "점근 영역 아님"으로 판정하며 기준을 완화하지 않습니다.

### 0.4 판정 기록
`validation/records/<단계>-<시험>-<날짜>.md` 에 입력 해시, 코드 커밋, 기준 커밋, 측정값, 판정, 비고를 남깁니다. 불통과도 같은 형식으로 남깁니다.

## 단계 1. 기본 유동 (단상, 고정/이동 경계)

목표: 축대칭 이산 연산자, 투영법, 변수밀도 Poisson, IBM 이 올바른지.

| ID | 시험 | 비교 대상 | 측정 지표 | 통과 기준 (근거) |
|---|---|---|---|---|
| 1-A | 제조해(MMS): 축대칭 비정상 Navier–Stokes, 축 근처 포함 | 제조해 (직접 구성) [R-27] | 속도·압력 L2, L∞ 오차, p_obs | p_obs ≥ p_f − 0.3 (속도·압력, L2) (T)+(C: 허용폭 0.3) |
| 1-B | 원관 Hagen–Poiseuille 유동 (축대칭) | 해석해 u_z = (G/4μ)(R² − r²) | L2 오차, p_obs | 위와 동일 (T) |
| 1-C | 평면 2D 리드구동 공동 Re=100, 1000 (planar2D 모드) | Ghia et al. 표 [R-18] — 표 수치는 사용 전 원문에서 확인 필요 | 중심선 속도 분포 | 최세 격자에서 표값 대비 차이가 우리 GCI 추정 불확도 범위 내 (U) |
| 1-D | 변수밀도 정수압: 밀도비 1000 두 층 정지 | p = ρ g h 해석해 | 허위 속도 max|u|, 압력 오차 | max|u| ≤ 기계정밀도 수준 × 상수 (잠정 1e−10 m/s, (P)+(C)) — 균형력 배치면 이론상 0 |
| 1-E | IBM: 등가속 구 (고 Re, 초기 순간) | 포텐셜 부가질량 m_a = (1/2)ρ(4/3)πa³ — 고전 결과, 원전 미확인 (교과서 확인 필요) | 시작 직후 힘 F = m_a a | 3격자 외삽값과 해석해의 차이 ≤ GCI (T)+(U) |
| 1-F | IBM: 등가속 원판 (축 수직 운동) | 무한유체 부가질량 (8/3)ρa³ [R-21: 2차 출처 확인] | 시작 직후 힘 | 1-E 와 동일. **평평한 바닥판 하중의 핵심 검증** |
| 1-G | IBM: 저 Re 구 정상 이동 | Stokes 항력 F = 6πμaU (고전 해석해) | 항력, p_obs | (T) |
| 1-H | 물체 고정 좌표계 모드 vs IBM 모드 (D-04 채택 시) | 서로 | 1-F 의 힘 이력 | 두 결과 차이 ≤ 두 GCI 합 (U) |

비고: 1-E, 1-F 의 해석해는 "부가질량 × 가속도"이며 점성·자유수면이 없는 조건에서만 성립합니다. 시험 조건은 그에 맞게(초기 극단 시간, 큰 Re) 설정합니다.

## 부록. 참조 데이터 공백 요약 (정직한 현황)

- **축대칭 평평한 원판의 공기 완충 입수에 대해, 불확도가 제시된 정량 실험 데이터를 아직 확보·확인하지 못했습니다.** 후보 문헌은 서지 수준만 확인됐습니다. 따라서 현재 계획으로는 단계 3 의 "물리 검증(VALIDATED)" 판정이 불가능하며, 확보 전까지 축대칭 결과는 "검증(VERIFIED) + 수치 독립성 확인" 수준에 머뭅니다. 이는 D-14 로 관리합니다.
- 해석해 기반 시험(단계 1, 2, 4 의 대부분)은 문헌 없이도 유도 가능하므로 판정 근거가 확보되어 있습니다.
