# 03. 단계별 검증 계획

문서 상태: 초안 v0.1. **각 단계의 통과 기준은 해당 단계의 첫 실행 전에 사용자 승인 후 커밋으로 잠급니다.** 아래 수치 중 "잠정"으로 표시된 것은 아직 잠기지 않은 제안값입니다.
문헌 `[R-xx]`의 확인 수준은 `06_references.md` 참고. "미확인"으로 표시된 자료는 확인 전까지 통과 기준의 근거로 쓰지 않습니다.

---

## 0. 공통 원칙

### 0.1 검증(Verification)과 확인(Validation)의 구분
- **검증(코드 검증, VERIFIED):** 방정식을 맞게 풀었는가. 해석해·제조해(MMS) 대비 오차와 수렴 차수로 판정 [R-27].
- **확인(물리 검증, VALIDATED):** 맞는 방정식을 풀었는가. 실험/문헌 대비 비교 오차를 수치·입력·실험 불확도와 함께 판정 [R-28].
- **실행 성공(RUN_COMPLETED/RUN_HEALTHY)은 위 둘 어느 것도 아닙니다** (`02_design_document.md` §5).

### 0.2 통과 기준의 근거 유형
각 기준에는 아래 근거 유형 중 하나를 명시합니다.

| 기호 | 근거 유형 | 설명 |
|---|---|---|
| (T) | 이론적 수렴 | 이산화의 형식 차수 p_f. 관측 차수 p_obs 가 점근 영역에서 p_f 에 근접해야 함 |
| (U) | 불확도 기반 | 비교 오차 E = S − D 를 검증 불확도 u_val = sqrt(u_num² + u_input² + u_D²) 와 비교 [R-28]. u_num 은 GCI 등 격자 수렴으로 추정 [R-25, R-26] |
| (P) | 물리적 한계/보존 | 보존 법칙, 물리적 상한 (예: ρ_w c_w V). 위반은 곧 오류 |
| (C) | 관례값 | 문헌 근거가 아닌 공학적 관례. **관례임을 명시**하고 실행 전 잠금 |

### 0.3 수렴 시험 공통 절차
- 최소 3개 격자, 균일 세분화비 r ≥ 1.3 (잠정, (C)) [R-25].
- 시간 간격도 같은 방식으로 3단계.
- 관측 차수 p_obs, Richardson 외삽값, GCI 를 함께 보고. 진동 수렴/발산하는 경우 "점근 영역 아님"으로 판정하며 기준을 완화하지 않습니다.

### 0.4 판정 기록
`validation/records/<단계>-<시험>-<날짜>.md` 에 입력 해시, 코드 커밋, 기준 커밋, 측정값, 판정, 비고를 남깁니다. 불통과도 같은 형식으로 남깁니다.

### 1.1 P1 확정 기준 (사용자 승인 2026-10-21, 코드 작성 전 고정)

이 절의 수치·정의는 P1 코드 작성 **전에** 커밋되었습니다. 결과를 본 뒤 변경하지 않으며, 불통과는 `FAILED_<사유>` 로 기록합니다.

**공통 정의**
- 수렴 차수 p_obs = ln(E_{N/2} / E_N) / ln 2, **가장 고운 두 격자**로 계산.
- "오차 단조 감소": 사용한 모든 격자에서 N 이 커질수록 해당 오차가 줄어야 함.
- 속도 오차: 계산하는(경계에서 지정되지 않은) 모든 면의 속도 성분(r·z 두 성분을 한 집합으로)과 해석해의 차이. L2 는 면 제어체적(축대칭은 r 가중) 가중 평균 제곱근, L∞ 는 최댓값.
- 압력 오차: 셀 중심 압력. 압력은 상수만큼 정해지지 않으므로 계산값·해석해 각각 체적 가중 평균을 뺀 뒤 비교. 압력은 해당 시각의 속도로부터 별도 압력 방정식을 풀어 구함.
- 압력 방정식 반복 해법 허용치(상대 잔차): 투영 1e−12, 출력 압력 1e−13. 허용치 미달로 끝나면 해당 실행은 `FAILED_SOLVER`.
- 시간 적분: 3단 SSP Runge–Kutta, 각 단계 투영. 대류항 2차 중심차분, 균일 격자(Δr, Δz 일정).

**1-A 제조해 (축대칭)**
- 영역 r ∈ [0, 1] (r=0 축, r=1 벽 — 해석해 속도 지정), z ∈ [0, 1] 주기.
- 해석해: u_r = −2π r (1−r²)² cos(2πz)·A(t), u_z = 2(1−r²)(1−3r²) sin(2πz)·A(t) + B(t), p = cos(πr) cos(2πz)·C(t), A = 1 + 0.5 sin t, B = 0.5 cos t, C = 1 + 0.5 sin 2t. (발산 0, r=1 에서 u_r = 0, u_z = B(t))
- (a) ρ = 1, μ = 0.01. (b) ρ = 5.5 + 4.5 cos(πr²) cos(2πz − t), μ = 0.01 [1 + 0.5 cos(πr²) sin(2πz)].
- 원천항은 해석해를 운동량 방정식에 대입해 계산. 초기 속도는 해석해를 투영한 값.
- 격자 N × N, N = 32, 64, 128, 256. Δt = 0.064 Δr (Δt ∝ Δx). 종료 시각 T = 0.1.
- **통과**: (a), (b) 각각 ① 모든 오차 단조 감소 ② 속도 L2·L∞, 압력 L2 의 p_obs ≥ 1.7 ③ 압력 L∞ 의 p_obs ≥ 1.5. 근거: 설계 차수 2 (T), 허용폭 0.3·0.5 는 관례값 (C).

**1-B 원관 유동 (축대칭)**
- r ∈ [0, 1] (축, 벽 u = 0), z 주기 길이 1, Nz = 4. ρ = 1, μ = 1, 체적력 G = 4 (z 방향) → 해석해 u_z = 1 − r², 유량 Q = π/2.
- Nr = 16, 32, 64, 128. Δt = 0.25 Δr². 초기값 = 해석해. 정상 상태: 매 시간 단계 속도 변화 최댓값 / 속도 최댓값 ≤ 1e−12.
- 유량 Q_h = Σ 2π r_c Δr u_z (중심 반경 r_c, 면 속도).
- **통과**: 속도 L2 오차와 유량 상대오차 각각 ① 단조 감소이고 p_obs ≥ 1.7, 또는 ② 모든 격자에서 상대오차 ≤ 1e−10 (해석해가 이산식에서 정확히 표현되는 경우). 근거: 해석해 + 설계 차수 (T), 허용폭 (C). L∞ 는 보고만.

**1-C Taylor–Green 와류 (평면 2D)**
- [0, 2π]² 주기. ρ = 1, ν = 0.01. u = sin x cos y e^{−2νt}, v = −cos x sin y e^{−2νt}, p = ¼(cos 2x + cos 2y) e^{−4νt}.
- N = 32, 64, 128, 256. Δt = 0.2 Δx. T = 1. 초기값 = 해석해를 투영한 값.
- **통과**: ① 모든 오차 단조 감소 ② 속도 L2·L∞, 압력 L2 의 p_obs ≥ 1.7. 근거: (T)+(C). 압력 L∞ 는 보고만.

**1-D 밀도비 1000 정수압**
- 영역 [0, 1] × [0, 1] m, 모든 변 벽(u = 0). 축대칭 경우는 r=0 이 축. g = (0, −9.81) m/s².
- 아래 물 ρ = 1000, μ = 1e−3 / 위 공기 ρ = 1, μ = 1.8e−5. 경계면 z_i = 0.5 (격자면 일치) 또는 0.5 + Δz/2 (셀 중심).
- 셀·면 밀도는 해당 제어체적의 정확한 평균 (P1 에서 밀도는 주어진 함수).
- 평면 2D·축대칭 × N = 32, 64 × 경계면 2종 = 8 실행. 초기 속도 0, Δt = 1e−3 s, 1000 단계.
- **통과**: 8 실행 모두 ① 전 과정의 max|u| ≤ 1e−8 m/s ② 1000 단계 후 max|p̃ − p̃_exact| / (ρ_w g H) ≤ 1e−10 (H = 1 m, p̃ 는 평균 제거 압력). 근거: 이산 정수압 평형이 정확히 존재 (P), 수치 여유 (C).

**범위 메모**: 국소 격자 세분화는 P1 에서 구현하지 않고, 필요해지는 P4 에서 별도 제조해 시험과 함께 도입합니다 (2026-10-21, 코드 작성 전 결정).

### 1.2 P2 확정 기준 (사용자 승인 2026-10-22, 코드 작성 전 고정)

이 절의 수치·정의는 P2 코드 작성 **전에** 커밋되었습니다. 결과를 본 뒤 변경하지 않으며, 불통과는 `FAILED_<사유>` 로 기록합니다.

**판정 형식 변경 (사용자 승인 2026-10-22, 코드 작성 전)**
- 위 표의 원안은 "3격자 외삽값과 해석해 차이 ≤ GCI", 1-H 는 "차이 ≤ 두 GCI 합" 이었습니다.
- GCI 의 안전계수(1.25 등)는 원문 미확인 관례값이고 [R-25, R-26 서지만 확인], 점근 영역 밖에서는 판정이 불안정합니다.
- 그래서 아래의 P1 과 같은 형식으로 바꿉니다. GCI 와 Richardson 외삽값은 **보고만** 합니다.

**공통 정의**
- 모든 시험은 축대칭 (물체가 축을 따라 운동). P1 과 같은 균일 엇갈림 격자.
- p_obs, "오차 단조 감소"의 정의는 §1.1 과 같음. 상대오차 = |F_h − F_exact| / |F_exact|.
- 압력 방정식 허용치는 §1.1 과 같음 (투영 1e−12, 출력 압력 1e−13). 미달 시 `FAILED_SOLVER`.
- 힘 F 는 물체 표면에 작용하는 유체력의 축 방향 성분. 압력 적분 (1-G 는 압력 + 점성 응력, 2026-10-22 부터 제어면 운동량 수지로 측정 — 1-G 항목의 변경 기록).
- "시각 0 의 힘": 유체 정지, 물체가 정지 상태에서 가속도 A 로 출발하는 순간. 점성·대류 항이 0 이므로 압력 방정식만으로 정해지며 시간 간격과 무관.
- 공통 통과 조건 **(★)**: ① 상대오차가 모든 격자에서 단조 감소 ② 가장 고운 격자의 상대오차 ≤ 2 % ③ p_obs ≥ 0.8.
- 근거: 해석해 (T). 날카로운 IBM 의 표면 힘 설계 차수는 1~2 이므로 하한 0.8 은 "최소 1차, 여유 0.2" 인 관례값 (C). 2 % 도 관례값 (C).
- 바깥 경계: 1-E, 1-F(a), 1-G 는 해석해의 속도를 경계 속도로 지정합니다 (계산 영역 크기 오차 제거). Lamb Art. 337 은 바깥 벽이 지름의 여러 배 떨어져 있어도 결과를 크게 바꾼다고 명시합니다 [R-30].

**1-E 갑자기 가속하는 구**
- a = 1, ρ = 1, A = 1 (축 방향). 영역 r ∈ [0, 3], z ∈ [−3, 3]. 바깥 경계 = 이중 원천 해 (Lamb Art. 92).
- 격자 a/Δ = 8, 16, 32, 64.
- (a) 판정: 시각 0 의 힘, 해석해 F = −(2/3)πρa³ A. 통과 (★).
- (b) 보고만: 물체가 격자 몇 칸을 지나는 동안의 힘 이력과 새로 드러나는 셀에 의한 압력 튐 크기.

**1-F 갑자기 가속하는 원판**
- (a) 판정: 납작한 회전타원체, 반지름 a = 1, 축 방향 반두께 c = 0.2.
  - 해석해: 부가질량 = k·ρ(4/3)πa²c, k = α₀/(2−α₀) (Lamb Art. 114 식 (6), (12)). α₀ 는 시험 코드 안에서 수치 적분으로 구함.
  - 미리 계산한 참고값은 2.5198 ρa³ (판정에는 코드에서 계산한 값을 씀).
  - 바깥 경계 = Art. 114 식 (8) 의 퍼텐셜. 영역 r ∈ [0, 2], z ∈ [−1, 1].
  - 격자 a/Δ = 16, 32, 64, 128. 통과 (★).
- (b) 보고만: 평판 원판 (원기둥), a = 1, 두께 h = 0.1, 직각 모서리.
  - 격자 a/Δ = 40, 80, 160 (두께 4, 8, 16 칸, 격자면에 정렬).
  - (8/3)ρa³ 와의 차이, 수렴 경향, 모서리 근처 압력의 격자 의존성을 보고합니다. 정확한 해석해가 없어 판정에 쓰지 않습니다.

**1-G 저 Re 구 (Stokes 항력)**
- 구 고정, 균일 흐름 U. a = 1, ρ = 1, U = 1, μ = 1000 (Ua/ν = 1e−3).
- 바깥 경계 = Stokes 해 (Lamb Art. 337 식 (11)). 영역 r ∈ [0, 4], z ∈ [−4, 4]. 격자 a/Δ = 8, 16, 32, 64.
- 정상 상태 판정은 1-B 와 같음 (속도 변화 최댓값/속도 최댓값 ≤ 1e−12).
- 해석해 6πμaU. 대류에 의한 차이(Oseen 보정 3/8·Ua/ν = 3.75e−4, Lamb Art. 343)는 기준 대비 무시.
- 통과 (★).
- **측정 방법 (2026-10-22 변경, 아래 변경 기록): 제어면 운동량 수지.**
  - 물체를 둘러싼 닫힌 면 S (옆면 r = 2.5a, 윗면·아랫면 z = ±2.5a; 모든 격자에서 격자면과 맞음)에서
    F_z = ∮_S [ −p n_z + (τ·n)_z − ρ u_z (u·n) ] dA (축대칭, 2π 포함).

**공통 정의 (초안)**
- 모델: 축대칭 고체 (r–z 단면), 선형 탄성, 소변형. 미지수는 절점 변위 u_r, u_z. 축(r = 0) 절점은 u_r = 0.
- 요소: **8 절점 2차 사각형 (Q8), 3×3 가우스 적분** (추천안, 결정 D-28 아래). 질량은 일관 질량행렬 (`02` §3.9). 체적·면적분에 2πr 가중.
- 시험 물성: 무차원 E = 1, ρ = 1, ν = 0.3 (따로 적지 않으면). 논문 재료(D-02)와 무관합니다.
- 오차 정의:
  - 변위 L2 상대오차 = sqrt(∫|u_h − u|² 2πr dA / ∫|u|² 2πr dA). 적분은 요소 3×3 가우스점.
  - 응력 L2 상대오차 = 같은 방식으로 네 성분 (σ_rr, σ_θθ, σ_zz, σ_rz) 을 한 집합으로. 응력은 가우스점에서 변위로부터 직접 계산 (회복 없음).
  - 절점 회복 응력 (4-B 에서 판정): 요소의 2×2 가우스점 응력을 요소 안에서 1차식으로 꼭짓점 절점까지 외삽하고, 이웃 요소 값을 평균합니다. 중간 절점은 양 끝 꼭짓점 평균.
- p_obs, "단조 감소" 정의는 §1.1 과 같습니다 (가장 고운 두 격자, 격자비 2).
- 연립방정식은 직접 해법 (대칭 띠/스카이라인 LDLᵀ). 해마다 잔차 ||K u − f|| / ||f|| ≤ 1e−10 을 확인하고, 넘으면 `FAILED_SOLVER`.
- 고유값은 같은 직접 해법을 쓰는 이동-역반복(부분공간 또는 Lanczos)으로 구하고, 고유값 상대 변화 ≤ 1e−12 에서 멈춥니다.
- 공통 통과 형식 **(★5)**: ① 오차가 모든 격자에서 단조 감소 ② p_obs ≥ (설계 차수 − 여유) ③ (적힌 경우) 가장 고운 격자의 오차 ≤ 상한.
  - 설계 차수 (T): 2차 요소의 변위 L2 3, 응력 L2 2, 고유진동수 4 (고유값 오차가 h^(2·2)). Newmark·HHT 시간 차수 2.
  - 여유: 변위·응력·시간 0.3, 고유진동수 0.5 (관례값 (C), P1 의 0.3 과 같은 방식).
- "정확 재현" 시험(4-A(a), 4-I): 정확한 해가 요소의 다항식 공간 안에 있어 반올림 오차만 남는 경우. 상한 1e−10 (변위), 1e−9 (응력) — 근거 (P), 수치 여유 (C).

**4-A 정적 정확도: (a) 패치 시험, (b) 제조해**
- (a) 패치 시험 (정확 재현)
  - 영역 r ∈ [0, 1], z ∈ [0, 1], 4×4 요소. 안쪽 꼭짓점을 정해진 무늬로 간격의 ±10 % 옮긴 **찌그러진 격자** (변은 직선, 중간 절점은 변의 가운데).
  - 해: u_r = c₁ r, u_z = c₂ z (c₁ = 1e−3, c₂ = −2e−3). 체적력 0 으로 평형이 정확히 성립합니다 (유도: 변형률이 상수 ε_rr = ε_θθ = c₁, ε_zz = c₂ 이고 σ_rr = σ_θθ, τ_rz = 0 이라 평형식의 모든 항이 0. 스크립트로 확인).
  - 경계: 축 u_r = 0, z = 0 에서 u_z = 0, r = 1 과 z = 1 에 해의 일정한 표면력 (σ_rr, σ_zz).
  - 통과: 절점 변위 최대 오차 / max|u| ≤ 1e−10, 가우스점 응력 최대 오차 / max|σ| ≤ 1e−9.
- (b) 정적 제조해
  - 영역 [0, 1]², 해: u_r = ε r cos(πr²/2) sin(πz), u_z = ε cos(πr²) cos(πz/2), ε = 1e−3. (u_r 은 r 의 홀함수, u_z 는 짝함수라 축에서 매끈함.)
  - 체적력 = −(평형식에 해를 넣은 값). 시험 코드에 식으로 넣고, 단위 시험에서 고차 차분과 비교해 식을 확인합니다.
  - 경계: r = 1, z = 0 은 해의 변위 지정, z = 1 은 해의 표면력 (표면력 → 절점력 변환도 시험).
  - 격자 N × N, N = 4, 8, 16, 32, 64 (정사각 요소).
  - 통과 (★5): 변위 L2 ① ② p_obs ≥ 2.7, 응력 L2 ① ② p_obs ≥ 1.7.

**4-B 두꺼운 원통의 내압 (Lamé, 평면 변형)**
- 측벽처럼 원통 모양이며, 원둘레 응력(σ_θθ, 후프 응력)과 압력 하중 변환을 시험합니다.
- 조건: 안 반지름 a = 0.5, 바깥 b = 1, 높이 H = 0.25. z = 0, H 면은 u_z = 0 (미끄럼 지지 → 평면 변형). r = a 에 압력 p = 1, r = b 는 자유.
- 해석해 (유도): u_z = 0, u_r = A r + B/r 꼴을 평형식 d/dr[(1/r) d(r u_r)/dr] = 0 에 넣고 σ_rr(a) = −p, σ_rr(b) = 0 으로 A, B 를 정하면
  - u_r = (1+ν) p a² / (E (b² − a²)) · [ (1−2ν) r + b²/r ]
  - σ_rr = p a²/(b² − a²) · (1 − b²/r²), σ_θθ = p a²/(b² − a²) · (1 + b²/r²), σ_zz = 2ν p a²/(b² − a²), τ_rz = 0.
  - 참고값 (E = 1, ν = 0.3): u_r(a) = 0.9533333333, σ_θθ(a) = 5/3.
- 격자 Nr = 4, 8, 16, 32 (r 방향), Nz = Nr/2 (정사각 요소).
- 통과:
  - 변위 L2 (★5) p_obs ≥ 2.7.
  - 안쪽 벽 절점 회복 σ_θθ 의 최대 상대오차: ① 단조 감소 ② p_obs ≥ 1.7 ③ 가장 고운 격자 ≤ 0.5 % (C). (논문의 첨두 응력은 표면값이므로 회복 응력을 판정합니다.)
  - 압력 하중의 절점력 합 = p · 2πa · H, 상대오차 ≤ 1e−12 (P). (P6 하중 전달의 기초)
- 보고만: 응력 L2, u_r(a) 오차.

**4-C 원판 굽힘 (바닥판, 정확한 3차원 탄성해)**
- 얇은 판에서 2차 요소가 지나치게 뻣뻣해지는 문제(잠김, locking)가 없는지 확인합니다. 바닥판의 응력이 논문의 핵심이라 둡니다.
- 조건: 반지름 a = 1, 두께 h, 중립면 z = 0. 윗면 z = h/2 에 균일 압력 p = 1 (아래 방향), 아랫면 자유. 가장자리 r = 1 의 모든 절점에 **아래 정확해의 변위를 지정**합니다. E = 1, ν = 0.3.
- 정확해 (이 절에서 유도): 변위를 다항식 u_r = r Σ a_ij r^(2i) z^j, u_z = Σ b_ij r^(2i) z^j (차수 ≤ 7) 로 두고, 평형식 두 개가 항등적으로 0, 윗면 σ_zz = −p, τ_rz = 0, 아랫면 σ_zz = τ_rz = 0 을 계수 방정식으로 풀었습니다. 남는 상수 3 개 (강체 이동, 반경 늘림, 순수 굽힘) 는 중립면 가장자리 고정 u_z(1,0) = 0, ∂u_z/∂r(1,0) = 0, u_r(1,0) = 0 으로 정했습니다.
  - u_r = r [ (39/20) z/h − (221/100) z³/h³ − (273/400) z/h³ ] + (273/400) r³ z/h³
  - u_z = r² [ −(117/200) z²/h³ + (273/800)/h³ ] + z² [ −(39/28)/h + (117/400)/h³ ] − (13/35) z − (273/1600) r⁴/h³ + (169/200) z⁴/h³ − (273/1600)/h³
  - (E = 1, p = 1, ν = 0.3 의 값. 스크립트가 평형식과 네 면 조건을 기호 계산으로 0 임을 확인.)
  - 이 정의에서 중앙 처짐 −u_z(0,0) = 273/(1600 h³) 는 Kirchhoff 고정 원판 p a⁴/(64D) 와 같습니다 (D = E h³ / (12(1−ν²))). 아랫면 중앙 σ_rr 은 h = 0.1 에서 47.75 (Kirchhoff 값 48.75 와 두께 효과만큼 다름).
- 격자 (요소 가로세로비 Δr/Δz = 5 고정):
  - (a) h = 0.1: (Nr, Nz) = (4, 2), (8, 4), (16, 8), (32, 16).
  - (b) h = 0.02 (얇은 판): (10, 1), (20, 2), (40, 4), (80, 8).
- 통과 (a), (b) 각각: 변위 L2 (★5) p_obs ≥ 2.7, 응력 L2 p_obs ≥ 1.7, 가장 고운 격자의 중앙 처짐 상대오차 ≤ 0.1 % (C, 잠김 감지용).
- 보고만: 아랫면 중앙 응력, 두께 방향 1 요소일 때의 오차 (잠김 정도).

**4-E 고유진동수 (진동 모드)**
- (a) 막대의 세로 진동 (ν = 0): 반지름 0.1, 길이 L = 1, z = 0 에서 u_z = 0, 나머지 자유.
  - 해석해 (유도): ν = 0 이면 λ = 0 이라 σ_zz = E ε_zz, σ_rr = σ_θθ = 0. u_r = 0, u_z = sin(kz) cos ωt 가 정확해이고, z = L 자유에서 cos kL = 0 → ω_n = (2n−1) π c / (2L), c = sqrt(E/ρ). 값 ω_n L/c = 1.5707963268, 4.7123889804, 7.8539816340.
  - 격자 Nz = 4, 8, 16, 32, Nr = 1. 가장 낮은 세 고유진동수 (반경 방향 모드는 ω ≳ 18 로 더 높음).
- (b) 두꺼운 원통의 반경 방향 진동 (평면 변형): 4-B 와 같은 지지 (z 면 u_z = 0), 안·바깥 면 자유.
  - 해석해 (유도): u_r = [C₁ J₁(kr) + C₂ Y₁(kr)] cos ωt, ω = k c_p, c_p = sqrt((λ+2μ)/ρ). σ_rr = (λ+2μ) ∂u_r/∂r + λ u_r/r 가 r = a, b 에서 0 → 2×2 행렬식 = 0 의 근 k.
  - (b1) a = 0.5, b = 1, H = 0.125: ω₁ = 1.4694732417, ω₂ = 7.4639423187. 격자 Nr = 4, 8, 16, 32, Nz = Nr/4. (z 방향으로 변하는 모드는 ω ≳ 15 로 더 높음 — H 를 작게 잡은 이유.)

  - 시험 코드는 판정 전에 해당 모드의 u_z 성분이 반올림 수준인지 확인해 모드를 식별합니다.
- 통과 (a)·(b1)·(b2) 의 각 진동수: (★5) ① ② p_obs ≥ 3.5 ③ 가장 고운 격자 상대오차 ≤ 1e−3 (C).
- (c) 보고만: 얇은 고정 원판 (h/a = 0.02, 가장자리 모든 절점 고정) 의 축대칭 1–3 차 진동수와 Kirchhoff 값 ω = λ² sqrt(D/(ρh))/a², λ² = 10.2158262299, 39.7711482365, 89.1041439740 (J₀(λ)I₁(λ) + I₀(λ)J₁(λ) = 0 의 근, 스크립트로 계산). 고체 모델과 판 이론의 차이(두께·고정 방식)가 있어 판정에 쓰지 않습니다.
- 고유진동수 계산은 P6 의 단방향 유효성 지표 (3)·(4) (T_load/T_wet, f_wet/f_dry) 에도 필요합니다.

**4-F 에너지 보존 (Newmark 평균가속도, 감쇠 없음)**
- 모델: 무차원 컵 (실제 모양과 같은 L 자 단면) — 바닥판 r ∈ [0, 1], z ∈ [0, 0.1]; 측벽 r ∈ [0.9, 1], z ∈ [0.1, 1]. 지지 없음 (자유-자유). 요소 크기 0.025.
- 처음 변위·속도: 4-A(b) 모양의 매끈한 장 (서로 다른 두 장). 하중 없음.
- Δt: 가장 낮은 탄성 모드에서 ω₁Δt = 0.05, 2000 단계 (가장 높은 모드는 ωΔt ≫ 1 — 무조건 안정 확인).
- 이론 (유도): 평균가속도법은 선형·무감쇠계에서 이산 에너지 ½ vᵀMv + ½ uᵀKu 를 정확히 보존합니다 (갱신식 u_{n+1} − u_n = Δt (v_n + v_{n+1})/2, M(v_{n+1} − v_n) = −Δt K (u_n + u_{n+1})/2 의 양변에 각각 (u_n+u_{n+1})ᵀK/2, (v_n+v_{n+1})ᵀ/2 를 곱해 더하면 에너지 차가 0).
- 통과: 전 단계 max |E_n − E_0| / E_0 ≤ 1e−8 (P, 초안 값 그대로, 반올림 여유 (C)).
- 같은 모델에서 HHT-α (α = −0.1) 와 Rayleigh 감쇠를 켠 실행: 매 단계 에너지가 늘지 않음 (E_{n+1} ≤ E_n (1 + 1e−12)) (P).

**4-G 동적 제조해 (공간 + 시간 수렴)**
- 영역·경계는 4-A(b) 와 같고, 해는 u(r, z, t) = U(r, z) · [sin 2πt + cos 2πt] (U 는 4-A(b) 의 장). ρ = 1. 체적력에 관성 ρ ∂²u/∂t² 를 포함합니다.
- 처음 변위·속도는 해에서, 처음 가속도는 운동방정식을 풀어 얻습니다. 종료 T = 1.
- 격자 N = 8, 16, 32, 64, Δt = 0.05 · 8/N (시간·공간 함께 세분; 시간 오차가 지배하므로 기대 차수 2).
- 통과 (★5): t = T 의 변위 L2 오차 ① ② p_obs ≥ 1.7. Newmark 평균가속도와 HHT-α (α = −0.1) 각각. 속도·응력 오차는 보고만.

**4-H 시간 적분의 이산 정확해 (한 모드)**
- 한 고유 모드만 들뜨게 하면 구조 전체가 1 자유도 계와 정확히 같아지므로, 시간 적분 공식을 반올림 수준으로 확인할 수 있습니다.
- 모델: 4-E(b1) 의 Nr = 16 격자. 계산한 1 차 모드 (ω₁ₕ, φ₁, φ₁ᵀMφ₁ = 1). 모드 좌표 q_n = φ₁ᵀ M u_n.
- 1 자유도 이론 (유도, 스크립트로 확인): HHT-α 를 다음으로 정의합니다 (α = 0 이면 Newmark 평균가속도).
  - M a_{n+1} + (1+α)(C v_{n+1} + K u_{n+1}) − α (C v_n + K u_n) = f
  - u_{n+1} = u_n + Δt v_n + Δt² [(½ − β) a_n + β a_{n+1}], v_{n+1} = v_n + Δt [(1−γ) a_n + γ a_{n+1}], γ = (1−2α)/2, β = (1−α)²/4.
  - 이를 (u, v, a) 의 3×3 증폭 행렬로 쓰고, 시험 코드가 그 고유값 (지배 근 ρ e^{±iθ}) 을 계산합니다.
  - Newmark (α = 0) 확인값: |지배 근| = 1, cos θ = (1 − Ω²/4)/(1 + Ω²/4), Ω = ωΔt (= tan(θ/2) = Ω/2). HHT 의 Ω → ∞ 극한 반지름 (1+α)/(1−α) (α = −0.1: 0.8181818, −0.3: 0.5384615) 와 수치가 일치함을 스크립트로 확인.
- 측정: e_n = q_n² − q_{n−1} q_{n+1} = C² ρ^{2n} sin²θ 이므로 ρ_meas = sqrt(e_{n+1}/e_n), cos θ_meas = (q_{n+1} + ρ² q_{n−1}) / (2ρ q_n). 앞 50 단계 (가짜 근의 감쇠) 뒤의 평균.
- 경우: Ω = 0.1, 1.0 각각에서
  - (a) Newmark 무감쇠, (b) HHT α = −0.1, −0.3,
  - (c) Newmark 에 Rayleigh 감쇠 C = a₀M + a₁K: 질량 비례 (a₁ = 0) 와 강성 비례 (a₀ = 0) 를 ζ₁ = 0.02 가 되게. 모드 감쇠비 ζ = a₀/(2ω) + a₁ω/2 (M, K 직교성에서 유도),
  - (d) Newmark, 계단 하중 f = F₀ M φ₁ (처음 정지): 이산해 q_n = q_s (1 − cos nθ), q_s = F₀/ω² (평균가속도법의 시간 대칭성에서 유도). 연속 극한의 동적 증폭계수 2 를 확인하는 시험입니다.
- 통과: (a)–(c) |ρ_meas − ρ| ≤ 1e−8, |θ_meas − θ|/θ ≤ 1e−8. (d) max_n |q_n − q_s(1 − cos nθ)| / q_s ≤ 1e−8. 모든 경우 다른 모드로 새는 양 ||u_n − q_n φ₁||_M / ||u_n||_M ≤ 1e−8. 근거 (T)+(P), 여유 (C).

**4-I 관성력: (a) 지정 운동, (b) 관성 해제 (자유-자유)**
- (a) 지정 운동 (몸체 좌표계 가속도 A, 체적력 −ρA)
  - 막대 반지름 0.2, 길이 L = 1, ν = 0.3, A = 1 (+z). 윗면 z = L 지지, 아랫면 z = 0 자유.
  - 정확해 (유도): σ_zz = ρ A z, 나머지 응력 0. u_r = −ν ρ A z r / E, u_z = ρ A (z² − L²)/(2E) + ν ρ A r²/(2E). 2차 다항식이라 정확 재현 대상 (사각형 요소).
  - 윗면에 정확해 변위를 지정 (a1) → 정확 재현 기준. 윗면 완전 고정 u = 0 (a2) → 지지 반력 합만 판정.
  - 통과: (a1) 정확 재현 (1e−10 / 1e−9). (a1)·(a2) 지지 반력 합 = ρ A π R² L, 상대오차 ≤ 1e−12 (P).
- (b) 관성 해제
  - 같은 막대, 지지 없음. 아랫면에 압력 q = 1 (+z 로 미는 힘). 코드가 합력과 질량에서 강체 가속도 A = q πR² / m 을 구하고 체적력 −ρA 를 더합니다. 강체 이동은 한 절점의 u_z 고정으로 막고, 결과에서 질량 가중 평균 u_z 를 뺍니다.
  - 정확해 (유도): σ_zz = −q (1 − z/L), 나머지 0. u_r = ν q r (L − z)/(E L), u_z = q (z² − 2Lz + ν r²)/(2EL) + 상수.
  - 통과: 고정한 절점의 반력 ≤ 1e−12 · qπR² (P). 평균 뺀 변위·응력 정확 재현 (1e−10 / 1e−9).
  - (b2) 4-F 의 컵 모델, 바닥면 균일 압력: 고정 절점 반력 ≤ 1e−12 × 합력 (P) 만 판정.

## 부록. 참조 데이터 공백 요약 (정직한 현황)

- **축대칭 평평한 원판의 공기 완충 입수에 대해, 불확도가 제시된 정량 실험 데이터를 아직 확보·확인하지 못했습니다.** 후보 문헌은 서지 수준만 확인됐습니다. 따라서 현재 계획으로는 단계 3 의 "물리 검증(VALIDATED)" 판정이 불가능하며, 확보 전까지 축대칭 결과는 "검증(VERIFIED) + 수치 독립성 확인" 수준에 머뭅니다. 이는 D-14 로 관리합니다.
- 해석해 기반 시험(단계 1, 2, 4 의 대부분)은 문헌 없이도 유도 가능하므로 판정 근거가 확보되어 있습니다.
