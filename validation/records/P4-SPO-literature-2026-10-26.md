# 개발 기록: 이동 물체 가짜 압력 진동 — 문헌과 우리 코드 대조, 해결책 후보 (2026-10-26) — 판정 아님

관련 기록: `P4-dev-3F-floor-2026-10-26.md` (원판 바닥이 격자 줄을 넘을 때마다 젖은 고리의 압력이 약 1 MPa 로 3–4 단계 튐).

## 1. 문헌 (확인 정도는 `docs/design/06_references.md` R-39–R-42)

| 문헌 | 확인 | 내용 |
|---|---|---|
| Xie, Lin, Stoesser 2022 (R-39) | 원문 | 주원인은 경계 근처 셀의 **국소 질량 보존 오류** (죽는 셀·새로 생기는 셀, §2.3). 연속 식을 열린 면 비율과 물체 속도로 (u − U_B)θA 꼴로 쓰면 (식 17) 절단 셀의 부피 변화가 일관되게 들어간다. 진동은 격자를 줄이거나 **Δt 를 키우면** 작아진다 (§4.2, 그림 8: CFL 0.025 → 0.2 로 갈수록 매끄러움). 죽는 셀은 속도 = 물체 속도, 새 셀은 물체 속도에서 시작해 운동량 식을 푼다 (§3.5). |
| Olshanskii, von Wahl 2024–25 (R-40) | 원문 (arXiv) | 경계 CFL = V Δt / h 가 작을수록 진동이 커지고, 순간 압력이 O(Δt⁻¹) 로 커진다. 이웃 시각의 발산 조건이 서로 달라 생기는 가짜 퍼텐셜이 1/Δt 로 커진다는 설명 (§4). |
| Seo, Mittal 2011 (R-41) | **원문 미확인** | (R-39, R-40 인용) 압력·속도 보정 식에만 절단 셀을 쓰고 작은 셀은 가상 병합. 진동 약 한 자릿수 감소. |
| Lee 외 2011 (R-42) | **원문 미확인** | (R-40 인용) 고체→유체 점의 압력 불연속, 유체→고체 점의 속도 불연속. 질량 원천/흡수 항으로 완화. |

## 2. 우리 코드와 대조

| 항목 | 우리 코드 (`src/flow/solver.cpp`, `src/body/cut_cell.cpp`) | 문헌과 비교 |
|---|---|---|
| 연속 식 | 열린 면 비율 + 물체 경계 유출 W·∫n_z dA (`face_flux_rhs`) | R-39 식 17 과 같은 꼴. 여기는 이미 맞다. |
| 운동량 면 분류 | 면 중심이 물체 안이면 고체, 고체 이웃이면 경계 보간 (점 판정, 시간에 따라 계단식으로 바뀜) | R-39 는 절단 셀에서도 운동량을 푼다. 우리는 줄을 넘는 순간 면 종류가 한꺼번에 바뀐다. |
| 압력 미지수 | 열린 면이 모두 "운동량이 정한 면" 이면 그 셀은 압력 미지수에서 빠지고 **그 셀의 발산을 버린다** (`div_b[c] = 0`, 1093행) | R-39·R-41 이 주원인으로 꼽는 **국소 질량 보존 오류**가 바로 여기서 생긴다. 바닥 바로 아래 얇은 셀 줄이 늘 이 상태다. |
| 줄 넘김 순간 | 얇은 셀 줄이 한 줄 아래로 옮겨 가며, 유체 영역이 보는 "밀려나는 부피" 가 경계 보간 면의 값으로 갑자기 바뀐다 | 시간 불연속 → 비압축 물에서 압력 충격 |
| Δt | 늘어나는 격자 a/64 에서 Δt ≈ 2–3×10⁻⁶ s → 경계 CFL = V Δt / h ≈ 0.005–0.008 | R-39 의 가장 작은 경우 (0.025) 보다도 3–5 배 작다. 진동이 클 조건이다 (P4 조건 Δt × ¼ 이 오히려 불리). |

## 3. 해결책 후보

| 안 | 내용 | 장점 | 단점·위험 |
|---|---|---|---|
| **A. 얇은 셀 병합 (추천 1순위)** | 압력 미지수에서 빠지는 얇은 셀의 발산 (물체 유출 W·n_z dA 포함) 을 유체 쪽 이웃 셀에 더해 한 덩어리로 질량을 맞춘다 (R-41 의 가상 병합과 같은 생각). 둘 사이 경계 보간 면의 플럭스는 서로 지워진다. | 바닥면 전체의 n_z 면적은 줄을 넘어도 연속이므로, 유체 영역이 보는 밀려나는 부피가 시간에 연속이 된다. 고칠 곳이 압력 우변 한 곳이라 작다. | 얇은 셀 자체는 발산이 0 이 아닐 수 있다 (부피가 작아 VOF 영향은 작을 것으로 예상, 확인 필요). |
| B. 경계 보간 면 값을 질량에 맞춤 | 얇은 셀의 연속 식이 정확히 맞도록 그 셀의 유체 쪽 면 속도를 정한다 (질량 원천/흡수 생각, R-42). | 모든 셀이 발산 0 | 경계 보간 (no-slip) 값을 덮어써 점성 경계 조건이 바뀐다. 옆면·모서리 셀 처리가 복잡하다. |
| C. Δt 키우기 | 경계 CFL 을 키워 진동을 줄인다 (R-39, R-40). | 코드 변경 없음 | P4 확정 조건 (Δt × ¼) 변경 = 사용자 승인 필요. 줄일 뿐 없애지 못한다. 공기 쿠션 구간 시간 해상도와 충돌. |
| D. 완전 절단 셀 운동량 (R-39 방식) | 절단 셀에서도 운동량을 풀고 죽는·새 셀을 그 방식으로 처리 | 가장 근본적 | 솔버 큰 개편. 지금 단계에 비해 과함. |
| E. 힘 값 거르기 | 힘 이력을 평활 | — | **쓰지 않는다.** 압력장 자체가 튀므로 원인을 가리고, 결과를 본 뒤의 측정 변경이 된다. |

## 4. 진행 방법 (제안)

1. A 를 개발용 스위치로 넣고 a/64 에서 확인: 튐 크기, 3-F 두 지표, 첨두 힘, 물 부피 보존 (`clipped_water`).
2. 효과가 있으면 정식 솔버 변경으로 커밋. 이 변경은 움직이는 물체가 있는 모든 시험에 영향을 주므로 **P2 이동 물체 시험과 P4 판정 시험을 다시 실행**한다 (이전 판정 기록은 그대로 둔다).
3. 3-F 기준과 측정 방법은 바꾸지 않는다.
4. R-41, R-42 원문은 사용자가 내려받아 주면 확인해 세부를 보완한다.
