# 논문 조건 입력 (`purpose = paper`)

아직 논문 조건이 정해지지 않아 비어 있습니다.

규칙:
1. 입력이 확정되면 `hcw lock <파일>` 로 잠급니다. 같은 폴더에 `<파일>.lock` (SHA-256) 이 생기며, 둘 다 커밋합니다.
2. 잠근 뒤 입력 파일이 한 글자라도 바뀌면 실행이 거부됩니다 (줄바꿈 CRLF/LF 차이는 무시).
3. 실행은 `config/machines.ini` 에 `workstation` 으로 등록된 기기에서, 커밋되지 않은 변경이 없는 빌드로만 허용됩니다.
4. 결과는 `results/paper/` 에만 저장됩니다.
5. 잠금을 풀어야 하면 `.lock` 파일을 지우는 이유와 날짜를 기록으로 남깁니다. 잠금 파일은 덮어쓸 수 없습니다.
